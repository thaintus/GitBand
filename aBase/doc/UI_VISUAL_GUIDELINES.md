# GitBind 桌面界面视觉规范

## 目标与范围

界面保持轻量 Git 身份管理工具的定位，以深蓝导航、浅灰工作区、白色卡片和蓝紫色主操作建立统一层级。视觉调整不得改变账号解析、认证隔离、绑定、Remote 更新、托盘或删除确认规则。

## 配色与排版

- 颜色统一定义在 `src/GitBinder.Desktop/App.axaml`，页面引用动态资源，避免在 ViewModel 中返回色值。
- 当前使用一致的浅色主题（`RequestedThemeVariant="Light"`）；不再让系统深色主题的输入控件混入浅色工作区。本轮不新增主题切换设置。
- 工作区 `#F3F5FA`，卡片 `#FFFFFF`，细边框 `#E2E7F0`，导航 `#142035`。
- 主要操作 `#465BE8`，成功/启用 `#147D70`，警告/默认标记 `#9A6116`，危险/禁用 `#BE3545`；状态同时保留文字，不只依赖颜色。
- 正文 `#1D293F`，次要文案 `#617087`，侧栏普通文字 `#A2B1CC`，侧栏选中文字 `#F2F5FD`。
- 中文优先使用 Microsoft YaHei UI，兼容 Microsoft YaHei、Segoe UI；路径和地址使用等宽字体。
- 页面标题 26px、区块标题 16px、正文/说明 13px、辅助信息 12px；保留清晰的标题与说明间距。

## 布局与组件

- 主窗口保持最小 960×640；左侧 216px 导航贯穿窗口高度，品牌区与导航列表分开，底部不增加已移除的本地运行说明。
- 主导航顺序固定为总览、账号、平台、项目；设置独立固定在左下角，以同规格线性齿轮图标加文字呈现，与主导航用轻量分隔线隔开。设置与主导航互斥高亮，保留悬停提示、键盘焦点和语言切换；窗口变高时只伸展主导航区域，设置仍贴近底部。
- 全局模式位于右侧工作区顶部，采用白色紧凑工具栏、线性图标与文字状态，保持当前账号及原有操作；左右留白 28px，与各页内容对齐。错误反馈进入统一结果弹窗，不挤占账号和按钮。
- 五个页面统一留白为左右 28px、上下 24px，标题与说明间距 5px；列表卡片间距 10px，统计和设置区块间距 14px。共用 card 样式默认 12px 圆角、1px 边框和轻阴影，内嵌操作区默认使用浅灰背景与 10px 圆角；项目列表采用下述单层卡片规范，使用 14px 圆角及细分隔线绑定区，不叠加整条浅色容器。
- 导航和功能图标使用原生 Path 几何，不使用依赖字体形状的装饰符号，不引入外部图标包。
- 总览优先展示账号、仓库、绑定和默认账号四张摘要卡；下方使用浅色紧凑说明卡及分支图标，避免大面积深色说明占据首屏。设置按通用、Git 环境、存储分区，检测操作靠近 Git 区标题。
- 账号、项目和平台列表均提供无数据空态及原有新增入口。长名称、账号、主机和地址在空间受限时省略并提供全文悬停提示，说明文案和设置路径可换行；设置中的只读路径直接使用可选择正文，不显示为输入框。
- 账号、项目和平台页面在标题下保留常驻搜索框，输入即按当前已加载数据做不区分大小写的包含匹配，忽略首尾空白；搜索不触发仓储读取、Git 操作或网络请求。
- 三个列表页统一在标题下 18px 处展示搜索框，左侧为搜索线图标，尾部为中性清空线图标并标注“清空搜索”悬停说明及无障碍名称，不使用红色危险删除样式。项目页将搜索框与右侧筛选数量整合为一条白色工具栏，保持单层边框及整体焦点提示。有数据但无匹配时显示独立提示，与无数据引导区分。
- 筛选保留条目实例、原有相对顺序和当前页查询条件；平台仍保持启用在前。新增/编辑/删除或再次载入后，按保留的查询条件重新筛选。
- 账号编辑、平台新增/编辑、分组编辑、克隆仓库、结果与确认弹窗统一白色标题/正文、40px 图标底座（12px 圆角）和淡色底部操作区，标题 20px。表单主体可滚动，底部操作保持可见；真实输入字段和凭据遮罩保留，说明及错误文字可选择复制。账号编辑的基本信息、HTTPS、SSH 三部分继续采用浅灰区块。
- 平台“新增”和编辑图标打开独立模态窗口，不在列表中展开表单；名称及 Host 分别标注字段名。取消、关闭或 Escape 不保存，保存中禁用重复提交与关闭；校验/保存失败留窗保留输入，成功关闭并按原筛选条件刷新列表。
- 提交邮箱标记为可选，留空提示明确“不携带邮箱、不继承全局邮箱”，并以可选择的说明文字提示按实际生效账号、仅影响新提交及平台限制。与“HTTPS 凭据编辑留空保留旧值”必须明确区分。账号已保存但 Git 配置同步失败时，单独说明持久化已成功及需要重试，不关闭编辑窗口，也不误报全部保存失败。

## 按钮与安全交互

- `primary` 用于新增/保存等主要操作，`secondary` 用于编辑等次要操作，`ghost` 用于弱化操作，`danger` 用于危险动作。
- 删除/移除统一为卡片或数据区右上角红色 `×`，悬停仍保持危险色，并保留操作提示及二次确认。通常距离上边/右边 8px、点击区 28×28px；项目页的项目和分组删除按钮与页内其他纯图标操作统一为 24×24px，保持各数据区右上角位置。
- 按钮与导航项使用独立 ControlTheme，避免 Fluent 原模板的悬停/选中颜色覆盖自定义状态。保留原生按钮命令与键盘行为，键盘焦点使用明确边框/焦点环。
- 删除确认中的取消为默认按钮，Escape 或关闭弹窗仍取消操作。
- 所有应用弹窗（账号、平台、分组、克隆、结果与确认）显式设置 CanMinimize=false、CanMaximize=false，仅保留标题栏关闭按钮；保持原有可调整窗口大小的能力，不通过禁用缩放或移除整个标题栏实现。系统文件/目录选择器沿用原生样式。
- Esc 按层级处理：展开的下拉先收起，下一次才关闭当前弹窗；确认等嵌套弹窗由活动窗口承载，取消只影响最上层。项目地址/路径内联编辑按 Esc 取消、不保存。没有弹窗/编辑时主窗口通过原 Close 路径处理 Esc，遵循关闭到托盘设置，不直接 Shutdown。
- 账号保存/私钥导入、平台/分组短时保存、主窗口启动配置同步及后台 Git/持久化操作期间防止 Esc 误退出；克隆中 Esc 只请求取消，等待任务结束后保留结果。保存成功的主动关闭必须放行，不能被命令仍处于运行中的瞬间状态挡住。普通页面加载不额外阻断 Esc。
- 项目绑定账号选择即切换；测试、解绑紧贴选择框，状态保持在右侧。禁止重新增加“保存绑定”按钮。
- Remote 协议转换仍只更新编辑内容；必须保存才写入仓库地址。不增加已移除的“刷新 Remote”。
- 当改绑后或测试/单项拉取前发现生效账号与地址协议不匹配，另用确认弹窗展示原地址、目标协议和目标地址；仅用户确认才直接执行切换。取消保留已保存的账号绑定与原地址，并停止本次连接；不能以“测试”为名静默改写 origin。双协议账号不强制切换，全局模式按实际生效账号提示。
- 账号/平台编辑等常用操作默认使用线性图标、32px 点击区及悬停/键盘反馈；项目页纯图标操作按下述紧凑规格单独收敛为 24px，不影响其他页面。新建等主要入口保留图标加文字，设为默认、启用/禁用等状态变更保留明确文字，不能仅凭陌生图标猜测。
- 列表卡片共用 CardHoverBorderBrush，悬停仅轻微强调边框。只读可选文字的选中色、辅助文字和等宽文字样式统一维护在 Theme.axaml，不在各页复制交互代码。

## 验证边界

### 项目页紧凑布局与传输入口

- 页头并列“添加仓库”（已有本地目录）与“克隆仓库”（打开独立模态窗口），不再展开页内克隆表单。弹窗提供账号、远程地址、父目录和新文件夹名称，明确全局模式优先级；未启动时取消/关闭不执行克隆，失败保留输入及可选中复制的错误正文，成功后关闭并刷新项目列表。
- 项目页留白为左右 28px、上下 24px；卡片内边距为横向 14px、纵向 12px，圆角 14px、间距 10px，使用弱阴影与单层细边框。标题区、绑定操作、本地路径依次排列；隐藏的地址编辑区不额外占据行间距。标题名称采用 15px 半粗体，协议与主机以 11px 辅助文字集中在名称下方，与 32px 仓库图标对齐。搜索与结果数量置于同一个 12px 圆角白色工具栏，数量使用轻灰底小区块。
- 项目页专属规则使用 `.projects-page` 类选择器限定作用域；不要使用不能匹配派生 ProjectsView 的 `UserControl.projects-page` 类型前缀。样式改动需区分静态解析与实际渲染结果。
- 账号选择框继续表示绑定，不重复增加绑定标签；保留生效账号、协议、主机及本地路径。绑定行仅使用顶部细分隔线，不再铺整条浅底；右侧以绿色文字显示生效账号、灰色文字显示生效原因，并提供省略及全文提示。完整 Remote 在主机的悬停提示与编辑区查看，读取失败提示仍可见。
- 项目页内所有 `Button.icon-action` 统一为 24×24px 点击区、6px 圆角，默认 12×12px 线性 Path 图标、普通笔画 1.4px、拉取笔画 1.5px；左侧分组数据卡图形按下述规格单独缩为 10px，保留同样点击区。默认规格覆盖项目卡片、分组新增及清空搜索，不改变页头文字按钮、输入控件、非按钮装饰图标及其他页面。拉取相关入口继续使用参考 IDEA“Update Project”的斜向左下箭头。标题区修改地址、拉取、删除直接透明同排呈现，不包裹整片灰底或额外内边距，组内间距 2px、上边距 4px，与 32px 仓库图标中心对齐；分组按钮间距同为 2px。拉取默认蓝色图标，悬停仍显示浅蓝背景，删除维持危险红色。每个纯图标按钮必须提供本地化悬停说明与 AutomationProperties.Name；键盘焦点环外扩 2px（Margin=-2）、圆角 8px、线宽 1.5px，保留清晰反馈。
- 页头“添加仓库”和“克隆仓库”统一 40px 高、10px 圆角，前者为白底细边框次要按钮，后者为蓝色主要按钮，均保留图标加文字，避免本地登记与远程克隆混淆。克隆入口参考 Git 分支形状，使用 16px 原生 Path、约 1.6px 圆头线条、三节点与右侧分支，不使用大尺寸图案或位图；数据项的拉取仍使用原斜向箭头，不改变含义。表单保存/取消仍为文字。删除叉号维持数据区右上角，测试/解绑紧贴账号框，状态靠右。
- 克隆弹窗中显示不定进度、当前生效账号及取消传输入口，传输及收尾刷新期间防重复操作和误关；不伪造下载百分比。窄窗口下表单可滚动，错误出现后自动滚入可见区域，底栏操作始终可见。目录选择器由当前活动窗口承载，不弹在模态窗后方。项目/分组拉取继续使用页面进度区，传输时冻结相关操作，结束后反馈并重新加载列表。

静态检查覆盖 XAML XML、主题资源、本地化键、命令/事件保留、长文本布局与差异检查。静态分析不替代 Avalonia 编译、实际窗口渲染、键盘交互及 Windows 缩放比例验收；构建、测试和打包仍须用户明确要求。

用户明确要求运行验证时，可按 `tests/GitBinder.UiSmoke/README.md` 启动隔离 UI 宿主。宿主加载真实 App 资源和五页视图，在中英双语及 1180×780 / 960×640 下渲染 PNG，并通过实际控件绑定/事件验证筛选和弹窗；后端全部为内存 Fake，不初始化真实数据库、托盘或 Git 服务。输出位于专用 `artifacts/`，须查看渲染图，不能只依据断言数量判断视觉质量。此验证不代表安装、系统键鼠/剪贴板、真实认证/拉取或不同 Windows DPI 已验收。

语言切换需要核对已经显示的主框架与弹窗正文，不可只检查切页后新建的控件。Avalonia 反射索引器绑定应通过真实 CLR 属性名 `Item` 通知刷新；同时保留 `CultureChanged`，以刷新 ViewModel 生成的导航和状态文案。

### 项目分组侧栏

- 项目列表左侧为 170px 分组栏，与右侧卡片保持 14px 间距；不使用贯穿侧栏的分隔线与额外右内距，左右列表独立滚动。每个分组项（含“全部项目”“未分组”）使用白色背景、独立 1px 浅色边框、10px 圆角、横向 10px/纵向 8px 内边距及 8px 项间距；悬停加深边框，选中采用浅蓝背景、弱蓝灰边框和左侧强调线，键盘焦点仍使用明确蓝色边框，不改变条目尺寸。
- 固定“全部项目”“未分组”，自定义分组显示名称和项目总数；搜索只过滤右侧列表，不改变分组总数或批量拉取范围。
- 标题旁加号打开居中分组弹窗，铅笔图标在同一弹窗内重命名，不再挤占侧栏显示表单。只有分组名称使用真正的输入框；说明和错误使用可选择正文。名称校验失败留窗重试，取消不保存，保存期间禁止重复提交和关闭。
- 拉取按钮位于每个分组项的右上角，与删除叉号同排，拉取在左、删除在最右；分组数据卡中的拉取、删除及重命名采用 10px 图标，普通线宽 1.2px、拉取线宽 1.3px，保留 24px 点击区、2px 按钮间距、原有悬停/焦点/禁用反馈及删除二次确认。分组名称为 13px 半粗体、数量为 11px 常规字重，保证名称为主要视觉信息。分组项固定为两个 24px 内容行、行间距 2px，使内置分组与自定义分组高度一致；标题与按钮使用独立布局列、6px 列间距并垂直居中，长分组名省略并提供全文悬停提示。数量与重命名图标位于下方，数量直接使用辅助文字，不再套白色徽章。内置分组不可重命名或删除，右上角仅显示拉取按钮。缩小规则仅作用于 `ListBox.project-groups` 内部，放在项目页默认图标样式之后，不影响标题新增分组、右侧项目按钮及分组下拉框。
- 项目路径行以文件夹图标和可省略路径呈现，悬停展示全文；右侧路径编辑按钮位于紧凑分组下拉框左侧，与下拉框另留 10px 外边距以区分用途，不另增卡片行高。分组下拉框采用 96×24px 标签式外观、6px 圆角、6/1px 横纵内边距、11px 文字及 8px 箭头，与相邻 24px 图标按钮居中对齐；常态浅灰底、无明显外边框，悬停弱描边，键盘焦点及展开状态用主色描边。仅作用于 `project-group-choice`，不影响绑定账号下拉框及其他页面；保留原生下拉与键盘行为、名称省略/全文提示及无障碍名称。分组变更失败恢复原选项。
- 每个分组提供拉取按钮，空分组不可拉取；确认文案说明操作完整分组。运行期间冻结项目及分组操作，保留取消入口；结束后汇总及逐项结果统一在可复制弹窗查看。

### 操作结果弹窗

- 账号、项目、平台、全局模式以及账号编辑表单的结果/错误不再占据页面底部，通常使用“操作结果”窗口；平台新增/编辑和克隆仓库的校验/操作错误保留在各自模态窗内，以可选中正文展示，避免重复弹窗打断修改。
- 结果与确认弹窗采用白色正文、轻量线性图标、固定标题区和淡色底部操作区。正文使用原生 SelectableTextBlock 配合 ScrollViewer，可直接选择并按 Ctrl+C 复制，不使用只读 TextBox，也不再提供“复制全部”按钮及复制状态。
- 结果弹窗初始高度随正文自适应，长内容限制正文高度并滚动；保留窗口大小调整、关闭按钮及复制快捷键说明。确认框的取消仍为默认操作，Escape 不执行确认。
- 通知串行显示，优先使用操作所属窗口作为父窗口，避免账号编辑错误被挡在后面。Escape 和关闭按钮关闭提示；相同错误再次发生仍提示。
- 正在认证及批量拉取的进度保留在页面，克隆进度保留在克隆弹窗内，不因每次进度刷新另开弹窗；分组拉取结束后一次性展示汇总和各项目结果。
