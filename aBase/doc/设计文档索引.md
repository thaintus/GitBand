## 已落地的设计决策（对原设计的调整）

以下调整已在代码中实现，作为对两份设计文档的补充说明：

1. **平台目录化**：原设计 `Platform` 为固定枚举（GitHub/Gitee/…/Custom），实际改为**用户可维护的平台目录**（`platforms` 表），支持名称/Host 自定义与启用/禁用；账号存 `platform_id` + `platform_name`。内置平台与自建平台地位相同。
2. **账号编辑三块化**：账号编辑页简化为「Git 信息 / HTTPS 账密 / SSH 私钥」三块；认证方式由填写内容自动推断；SSH 私钥改为上传模式（存 `%LOCALAPPDATA%\GitBind\keys\`）；移除 passphrase 输入。
3. **项目添加选择目录**：添加仓库改为目录选择器确定路径，不再手动输入。
4. **打包**：提供 Inno Setup 安装包（`build\installer.iss`）与一键构建脚本（`build\build.ps1`、`一键构建.bat`）。
