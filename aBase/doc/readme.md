此目录用于存放项目的设计资料、第三方对接资料及其他开发参考文档，包括但不限于：

- 系统设计、架构设计、技术方案等设计文档；
- 产品需求文档、原始需求说明等需求资料；
- 测试方案、测试规范等测试相关资料；
- 第三方平台、API、SDK、协议等对接文档；
- 其他用于需求分析、技术设计和功能实现的参考资料。

目录职责说明：

- 本目录保存的是项目开发的设计依据和参考资料；
- 项目实际发生的功能开发、需求调整、代码变更、数据库变更等迭代过程，应记录在「项目迭代文档」目录中；
- 在进行需求分析、方案设计、功能开发或问题排查前，应优先查阅本目录中与当前任务相关的资料。

判断原则：
原始需求、设计方案、第三方资料等放入本目录；基于这些资料实际完成了哪些开发和修改，记录到「iteration」目录。
