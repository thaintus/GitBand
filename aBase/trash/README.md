# trash 回收目录

本目录用于存放项目中不再需要、但暂不进行物理删除的文件，相当于逻辑删除的回收站。

将文件移动到本目录即视为逻辑删除，文件内容仍保留以备追溯，但不再参与项目正常开发与维护流程。

## 使用规则

- 当文件不再需要时，应将其移动到本目录，而非直接删除；
- 移入本目录的文件应保持原有文件名，便于需要时查找和恢复；
- 如需进一步说明删除原因，可在文件同级目录下补充同名 `.md` 说明文件；
- 本目录中的文件不作为需求分析、方案设计、功能开发或问题排查的参考依据；
- 如确需参考本目录中的历史文件，应明确其已被废弃，并以当前有效文档和代码为准；
- 定期清理本目录中确认无需保留的文件，避免回收站无限膨胀。

## 恢复规则

- 如需恢复某文件，将其从本目录移回原位置即可；
- 恢复后应检查文件内容是否与当前项目状态兼容，必要时同步更新。

## 判断原则

- **"文件还有没有用"**：不确定时先移入 `trash`，而非直接删除；
- **"trash 里的文件能否直接参考"**：不能，已被废弃，仅作追溯保留。
